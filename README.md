# Mini Imgur

Учебный проект за неделю: загружаешь картинку, сервер делает из неё маленькое превью, и всё это видно в приложении.

## Как это работает

Flutter (web) -> Nginx -> Go API -> RabbitMQ -> воркер

1. В приложении жму "+" и выбираю фото, оно уходит на `POST /images`.
2. API кладёт оригинал в SeaweedFS (S3), пишет запись в MongoDB со статусом `pending` и кидает задачу в RabbitMQ.
3. Воркер берёт задачу, уменьшает картинку до 300px, кладёт превью в S3 и ставит статус `done`.
4. Приложение каждые 3 секунды спрашивает список, поэтому `pending` сам превращается в превью.

Redis у меня пока используется только для кэша пользователей (это ещё с первых дней), к картинкам он не относится.

## Как запустить

```
docker compose up -d
cd frontend
flutter run -d chrome
```

Бэкенд доступен на http://localhost (Nginx на 80 порту).

## Что умеет API

- `POST /images` - загрузить картинку (только jpg и png, до 20 МБ)
- `GET /images` - список картинок
- `GET /images/{id}` - одна запись
- `GET /images/{id}/original` - оригинал
- `GET /images/{id}/thumbnail` - превью

## Что не доделано

- Нет удаления картинок, удалял руками через mongosh.
- Если RabbitMQ перезапустится, API теряет соединение и отдаёт 500, помогает только `docker compose restart app worker`. Надо сделать переподключение.
- Остались старые файлы с первого дня (`user_repository.go`, `user_usecase.go`, `delivery/http/handler.go`), надо убрать.
- HEIC с айфона не принимается, только jpg и png.
- Приложение всё время опрашивает сервер, даже если все картинки уже готовы.
